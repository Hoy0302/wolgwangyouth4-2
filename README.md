# 월광교회 청년예배 주보

모바일에서 보는 청년예배 주보입니다. `index.html` 파일 하나로 동작하며, 별도의 서버나 빌드 과정이 없습니다.

배포 주소: `https://<깃허브아이디>.github.io/<저장소이름>/`

---

## ⚠️ 공개 저장소입니다

이 저장소는 GitHub Pages 무료 배포를 위해 **공개(Public)** 상태입니다. 다음 두 가지를 기억해 주세요.

- 저장소에 올린 내용은 링크를 몰라도 **누구나 검색해서 볼 수 있습니다.** `index.html`의 `noindex` 설정은 배포된 주보 페이지가 검색에 잡히지 않게 할 뿐, 저장소 안의 파일까지 가려주지는 않습니다.
- 한 번 올린 내용은 나중에 지워도 **커밋 기록에 그대로 남습니다.**

그래서 다음 정보는 올리지 않는 편이 안전합니다.

- 청년들의 **휴대폰 번호** (동아리 리더 연락처 포함)
- **계좌번호 전체** — 필요하면 뒷자리를 가리거나, 계좌는 단톡방 공지로 따로 안내하는 방식을 권합니다
- 주소·생년월일 등 개인을 특정할 수 있는 정보

이름 정도는 대부분 문제되지 않지만, 판단이 서지 않으면 담당 목사님이나 간사님께 한 번 확인해 주세요.

## 매주 주보 수정하기

`index.html` 파일을 열면 아래쪽 `<script>` 안에 이렇게 표시된 부분이 있습니다.

```
/* =========================================================
   ★★★ 매주 이 블록만 수정하면 주보 전체가 갱신됩니다 ★★★
   ========================================================= */
const bulletin = { ... };
/* ================= 수정 영역 끝 ================= */
```

**이 `bulletin` 객체 안쪽만** 고치면 됩니다. 그 바깥은 건드릴 필요가 없습니다.

### 항목별 설명

| 항목 | 설명 |
| --- | --- |
| `issueNo` | 발행 호수 (예: `'제26-34호'`) |
| `date` | 발행일. **한글로 그대로** 적으면 됩니다 (예: `'2026년 8월 23일'`). 상단 헤더에는 `2026.08.23` 형식으로 자동 변환됩니다 |
| `theme` | 이번 주 주제. 인트로 화면과 소식 탭 상단에 함께 표시됩니다 |
| `introSubtitle` | 인트로 화면에서 주제 아래 들어가는 한 줄 설명 |
| `verse` | 주제 성구 |
| `orderBefore` | 설교 앞 예배순서. `['순서명', '담당']` 형태 |
| `sermon` | 설교 제목과 본문 |
| `orderAfter` | 설교 뒤 예배순서 |
| `nextWeek` | 다음 주 섬김. `header`(소제목)와 `items`(항목 목록) |
| `sermonSummary` | 아름다운 순 탭의 설교 요약 |
| `shareQuestions` | 셀 나눔 질문 목록 |
| `notices` | 주간 소식. 개수 제한 없이 추가·삭제 가능 |

### 예배순서에 찬양 곡 목록처럼 여러 줄 넣기

담당란에 배열을 넣으면 줄바꿈되어 표시됩니다.

```js
['경배와 찬양', ['내 안에 가장 귀한 것', 'winning all', '우리 주 하나님']],
```

### 주간 소식 작성하기

필요한 항목만 골라 쓰면 됩니다.

```js
notices: [
    {
        title: '청년부 여름 수련회 신청',        // 번호는 자동으로 붙습니다
        lines: [                                // 본문 줄 목록
            '일시: 8월 28일(금) ~ 30일(주일)',
            '장소: 00수양관'
        ],
        highlight: '오늘까지 셀 리더에게 신청해 주세요!'   // 빨간색 강조 문구
    },
    {
        title: '수련회 조편성',
        table: {                                // 표
            head: ['조', '인솔자', '차량'],
            rows: [
                ['1조', '홍길동', '1호차'],
                ['2조', '김월광', '2호차']
            ]
        }
    },
    {
        title: '수련회 포스터',
        image: {                                // 이미지
            src: 'poster.jpg',                  // 저장소에 같이 올린 파일 이름
            alt: '수련회 포스터',
            caption: '자세한 내용은 포스터를 확인해주세요'
        }
    }
]
```

소식이 하나도 없는 주에는 `notices: []` 로 비워두면 "이번 주 소식이 없습니다"가 표시됩니다.

### 그 밖에 바뀌는 정보

예배 시간표, 헌금 안내, 팀 모임 장소, 동아리 소개, 교회 연락처는 `bulletin` 객체가 아니라 HTML 본문과 `clubsData`에 들어 있습니다. 자주 바뀌지 않는 정보라 한 번 채워두면 계속 쓸 수 있습니다.

## 수정한 내용 반영하기

1. GitHub 저장소에서 `index.html`을 클릭
2. 연필 아이콘(Edit) 클릭
3. 내용을 고치고 아래 **Commit changes** 클릭
4. 1~2분 뒤 배포 주소에 자동 반영됩니다

파일 전체를 새로 올리려면 **Add file → Upload files**에서 같은 이름(`index.html`)으로 덮어쓰면 됩니다.

## 알아두면 좋은 것

- **한 파일로 끝납니다.** 폰트(Pretendard)만 외부에서 불러오고, 나머지 CSS·JS는 전부 `index.html` 안에 들어 있습니다.
- **화면 크기 대응.** 320px(갤럭시 Z 폴드 커버 화면)부터 태블릿까지 확인했습니다. 최대 폭 480px로 고정되어 PC에서도 모바일 비율로 보입니다.
- **글자 대비.** 모든 본문 글자가 WCAG AA 기준(4.5:1)을 넘도록 색을 맞춰뒀습니다. 색을 바꾸실 때 참고해 주세요.
- **이미지를 넣으려면** 저장소에 파일을 함께 올린 뒤 `image.src`에 파일 이름을 적으면 됩니다.
